# AGENTS.md

Personal monorepo of Violentmonkey userscripts (browser user scripts). License: AGPL-3.0-or-later with REUSE metadata.

## Layout

- One pnpm workspace package per userscript in `scripts/<name>/`: `package.json` + `vite.config.ts` (vite-plugin-monkey) + `src/main.ts`. No userscripts are committed yet.
- Shared code goes in `packages/lib/` when first needed (already covered by the workspace glob).
- Toolchain lives in `devenv.nix` (devenv.sh): node, pnpm, biome, treefmt, prek, cocogitto, reuse. These tools are only on PATH inside the devenv environment.

## Commands

Run everything through devenv — linters/formatters are not installed system-wide:

```sh
devenv tasks run ci # full chain: ci:typecheck -> ci:lint -> ci:build -> prek run --all-files
devenv shell -- pnpm build     # build all userscripts (pnpm -r build)
devenv shell -- pnpm --filter @userscripts/<name> build  # single script
devenv shell -- treefmt        # format (biome/nixfmt/yamlfmt/rumdl)
```

Entering `devenv shell` runs `pnpm install` and the git hooks automatically. devenv tasks do NOT run on entry — invoke them with `devenv tasks run`.

## Adding a userscript

1. Create `scripts/<name>/` with `package.json` (`name: @userscripts/<name>`; its `version` IS the userscript `@version`), `vite.config.ts`, `src/main.ts`.
2. `devenv shell -- pnpm --filter @userscripts/<name> add -D vite vite-plugin-monkey typescript`
3. Set `build: { fileName: '<name>.user.js' }` in the monkey config — it must match the release asset name.
4. Auto-update contract: `@updateURL`/`@downloadURL` point to `https://github.com/hnjae/userscripts/releases/latest/download/<name>.user.js`; bump the package `version` each release and keep the asset filename identical.

## Gotchas

- `.pre-commit-config.yaml` is generated by git-hooks.nix on shell entry (symlink into the nix store). Gitignored — never edit or commit it.
- reuse lint scans nested gitignored dirs (Git `--no-empty-directory` bug drops them from `git ls-files --ignored --others --directory`). The `**/node_modules/**` and `**/dist/**` annotations in REUSE.toml are the workaround — keep them.
- Every tracked file needs an SPDX header or REUSE.toml coverage. JSON files cannot carry comments — cover them in REUSE.toml instead.
- treefmt project root marker is `devenv.yaml`, not `flake.nix`.
- treefmt's Biome never reads the repository's `biome.json` — devenv.nix feeds its `formatter` section into `programs.biome.settings` instead. The `vcs` section must stay out of that copy: Biome resolves `.gitignore` relative to the config file, which lives in the Nix store. biome.json edits alone do re-trigger a devenv re-eval.
- biome.json is biome 2.5 schema: `vcs.clientKind` (not `client`), `linter.rules.preset` (not `recommended`).
- Commit messages must pass `cog verify` (conventional commits, enforced by the commit-msg hook).
